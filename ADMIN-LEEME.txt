PANEL PARA SUBIR TUS FOTOS (paso a paso)
========================================

Con este panel entras con tu correo y contraseña a  tusitio/admin.html  y puedes
añadir, cambiar, ordenar, ocultar y borrar los trabajos de la galería.
Las fotos nuevas aparecen en la página al instante, sin tocar GitHub.

Funciona con Supabase, un servicio gratuito (sin tarjeta). Incluye 1 GB para fotos,
que alcanza para cientos de trabajos porque el panel reduce cada foto automáticamente.

Haz esto UNA sola vez (toma unos 15 minutos):

PASO 1. Crear el proyecto
  - Entra a supabase.com y crea una cuenta (gratis).
  - Toca "New project". Ponle un nombre (por ejemplo: limpieza), una contraseña para
    la base de datos (guárdala) y elige la región más cercana. Deja el plan gratuito.
  - Espera 1 o 2 minutos a que termine de crearse.

PASO 2. Preparar la base de datos
  - Abre el archivo supabase-setup.sql con el Bloc de notas.
  - Busca la línea marcada con  <<<  y cambia TU_CORREO@ejemplo.com por el correo
    con el que vas a entrar. (Solo esa cuenta podrá cambiar las fotos.)
  - En Supabase abre "SQL Editor", toca "New query", pega TODO el contenido del archivo
    y toca "Run". Debe decir que terminó con éxito.

PASO 3. Crear tu usuario
  - En Supabase ve a "Authentication" > "Users" > "Add user" > "Create new user".
  - Escribe el MISMO correo del paso 2 y una contraseña. Marca "Auto Confirm User".

PASO 4. Cerrar el registro público (importante)
  - En "Authentication", dentro de la configuración de inicio de sesión
    ("Sign In / Providers" o "Settings"), desactiva "Allow new users to sign up".
  - Así nadie más puede crear cuentas.

PASO 5. Copiar los dos datos del proyecto
  - En "Project Settings" > "API" (o "API Keys") copia:
      * Project URL      (algo como https://abcdefg.supabase.co)
      * la clave pública (se llama "anon" o "publishable")
  - Abre config.js con el Bloc de notas y pégalos entre las comillas.
  - NUNCA pegues la clave "service_role" ni la "secret".

PASO 6. Subir a GitHub
  - Sube el config.js actualizado (y el resto de archivos de esta carpeta).
  - Espera 1 o 2 minutos y entra a  tusitio/admin.html

CÓMO USARLO
  - "Añadir trabajo": elige la foto de después (obligatoria) y, si quieres, la de antes.
    Escribe un título, elige el tipo de mueble y guarda.
  - Desde el celular, al tocar la casilla de foto puedes sacar la foto en el momento.
  - Las flechas cambian el orden. "Ocultar" quita un trabajo de la página sin borrarlo.
  - Si no subes ningún trabajo, la página muestra las fotos de ejemplo.

IMPORTANTE
  - Los proyectos gratuitos de Supabase se PAUSAN tras 1 semana sin uso. Si pasa, la
    página sigue funcionando, pero muestra las fotos de ejemplo en vez de las tuyas.
    Para activarlo de nuevo, entra a supabase.com y toca "Restore project".
    Entrar al panel o recibir visitas ayuda a que no se pause.
  - Si olvidas la contraseña: Supabase > Authentication > Users, y cámbiala ahí.
  - Los nombres de los menús de Supabase pueden cambiar un poco con el tiempo.
